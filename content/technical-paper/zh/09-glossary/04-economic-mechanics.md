# 经济机制

## 经济机制

- **TGE（Token Generation Event，代币生成事件）** — INT 成为即时链上资产且累积的 bINT 权益可供领取的时刻。
- **发放曲线** — 使用者奖励发放时程，依每月活跃使用者级距缩放。*见：04。*
- **转换比率（bINT → INT）** — 固定为 1:1：一单位 bINT 转换为一单位 INT 领取权。*见：04。*
- **每日 bINT 上限** — 使用者每日可赚取的最大 bINT 数量。上限由使用者的帐号等级设定；使用者的信任状态影响套用于每张收据的奖励率。*见：03 信任层、04 代币经济学机制。*
- **回购销毁（Buy-back-and-burn，BBB）** — 金库政策下用于减少 INT 流通量的基于规则销毁机制。执行细节属营运层面。*见：04。*
- **流动性启动池（Liquidity Bootstrapping Pool，LBP）** — 一种可调整权重的 DEX 池格式，用于启动新代币。考虑用于 INT 初始流动性。
- **单边流动性提供者（Single-sided LP）** — 仅需配对中两种资产之一的流动性提供。用于以锁定 LP 启动初始 INT 池。
