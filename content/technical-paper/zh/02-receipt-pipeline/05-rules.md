# 阶段 3 — 规则

## 2.6 阶段 3 — 正规表示式与规则层

正规表示式层**永远**在 LLM 之后执行。LLM 是快速的模式辨识器；正规表示式则是确定性的验证器。

### 正规表示式能捕捉、LLM 会遗漏的项目

规则层在四个类别上增加确定性验证：

1. **总额核对。** LLM 偶尔会四舍五入或标准化总额。规则层从 OCR 文字重新提取列印的总额，并在出现分歧时覆盖 LLM 的值。
2. **日期标准化。** 收据使用多种区域日期格式与在地化月份名称。所有变体统一收敛至 ISO 8601。
3. **币别消歧。** 混合币别代号依频率与商家所在地解析。
4. **税行侦测。** 在地化税率行（例如土耳其的 KDV）从列印文字侦测，而非由 LLM 推断。

### 规则目录

目录依类别组织：总额、税额、日期、币别与商家识别码。每个类别包含我们营运语言的在地化规则家族。具体模式与每条规则的权重由内部营运层管理。

### 信心度提升

每项验证通过的规则命中都会提升正规表示式层的信心分数。顺利核对的收据获得较高分数；未解析总额的收据则带有核对落差，信任评分器将其视为输入之一。该输入的权重由内部营运层管理。
