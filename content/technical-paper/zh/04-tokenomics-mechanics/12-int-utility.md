# INT 效用

## 4.27 效用表面

INT 在 Yumo Yumo 协议内承载六项功能。奖励功能的结算与领取基础设施已建成、待启用；其余功能为计划中，随协议表面成熟后启用。

| 功能 | 状态 | 描述 |
|---|---|---|
| **奖励资产** | 基础设施已建成，待启用 | 已验证的贡献当前在 bINT 会计层（4.14）中累积。bINT → INT 转换生命周期（4.4）的结算与领取路径已建成；链上 INT 分发随代币生成事件启用 |
| **质押资产** | 计划中 | 若启用质押，持有者可将 INT 锁入等级加权质押池（4.6） |
| **回购与销毁** | 若启用相关政策 | 金库可依照已发布的政策购买并销毁 INT（4.9） |
| **数据报告销毁** | 计划中 | 访问聚合社区数据报告的企业须按报告销毁指定数量的 INT（4.30） |
| **治理信号** | 计划中 | INT 加权信号，用于数据产品优先级、金库分配和生态系统拨款的决策 |
| **绑定 API 访问** | 计划中 | 匿名化数据产品的 API 消费者可能需要将 INT 绑定至其访问密钥 |

## 4.28 金库收入政策

INT 不承诺收益、升值或价格支持。若数据产品或其他活动产生收入，将其分配至金库、运营、质押激励或回购销毁，只能在已发布的政策及必要的法律审查完成后进行。

任何收入分配或质押激励，均会连同金额、期间、获授权的决策者及链上记录一并发布。本节不构成对未来收入、销毁或质押支付的承诺。

## 4.29 潜在收入来源

可能适用金库政策的收入来源包括：

- **匿名化数据销售。** 经 k-anonymization 处理的、聚合的收据级数据，通过分级 API 访问出售给快消品牌、零售商、研究机构和开发者。
- **联盟与推荐收入。** 价格比较的点击跳转至零售商或优惠券合作伙伴（计划中）。
- **高级订阅。** 高级个人分析和目标自动化功能（计划中）。

收入生成细节和匿名化架构描述于 05 数据架构与 API。

## 4.30 数据报告销毁

计划中的数据报告访问模式，可能要求为特定报告类型销毁 INT。若启用该模式，销毁会记录在链上，并公布报告类型和数量。

销毁会减少流通中的 INT 数量，但不保证代币价格、价值或需求的结果。每份报告的销毁数量仅在适用的金库政策和产品定价发布后生效。
