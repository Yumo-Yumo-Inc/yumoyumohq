# 05 — 数据架构与 API

本节定义 Yumo Yumo 的数据纲要与 API 接口。02 的管线输出、03 的信任决策与 04 的奖励会计均对应至此处定义的实体与事件形状。当前上线的接口是应用自身的路由加上公开价格账本；带版本的公开 REST API 与 B2B API 作为规划中的工作描述，并如此标注。

纲要公开发布，使协议各方能以相同方式读取相同记录。物理索引策略、供应商选择以及 B2B 产品的商业参数保留于运营文档中。

## 5.0 纲要原则

| 原则 | 结果 |
|---|---|
| 类型化记录 | 每个公开对象均为版本化且与纲要绑定 |
| 基于事件的账本 | 奖励会计派生自可审计的历史事件 |
| 数据分离 | 个人数据、聚合数据与链上摘要各自位于独立层级 |
| 可版本化 API | 字段新增/移除遵循向后兼容规则 |
