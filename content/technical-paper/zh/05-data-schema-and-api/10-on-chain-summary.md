# 链上资料摘要

## 5.9 链上资料摘要

依类别列出何者上链：

| 链上 | 链下 |
|---|---|
| 奖励 epoch Merkle 根（memo 密封） | 个别 `contribution_point_events` 列 |
| 价格 epoch Merkle 根 + 资讯清单杂凑（memo 密封） | bINT 余额与累积记录 |
| INT 铸造与转移事件（计划中） | 按使用者的奖励累积记录 |
| NFT 等级转换（计划中） | OCR 原始文字 |
| | 收据图像与品项 |
| | 信任分数讯号 |

规则是：**链上储存承诺与汇总；链下储存内容。** 使用者可验证其链下余额对照链上承诺，同时收据内容保留于链下资料层。

公开价格分类帐的发布流程与私人收据纳入证明定义于第 06 节。
