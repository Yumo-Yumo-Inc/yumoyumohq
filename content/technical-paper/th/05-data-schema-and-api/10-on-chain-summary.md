# สรุปข้อมูลบนเชน

## 5.9 สรุปข้อมูลบนเชน

สิ่งที่ขึ้นบนเชน ตามหมวดหมู่:

| บนเชน | นอกเชน |
|---|---|
| รูทเมอร์เคิลรางวัลต่อ epoch (memo seal) | แถว `contribution_point_events` แต่ละรายการ |
| รูทเมอร์เคิลราคาต่อ epoch + แฮชแมนิเฟสต์ (memo seal) | ยอดคงเหลือ bINT และบันทึกการสะสม |
| เหตุการณ์ mint และ transfer INT (วางแผน) | บันทึกการสะสมรางวัลต่อผู้ใช้ |
| การเปลี่ยนผ่านระดับ NFT (วางแผน) | ข้อความดิบ OCR |
| | ภาพใบเสร็จและรายการบรรทัด |
| | สัญญาณคะแนนความน่าเชื่อถือ |

กฎคือ: **บนเชนเก็บคำมั่นสัญญาและข้อมูลสรุป นอกเชนเก็บเนื้อหา** ผู้ใช้สามารถตรวจสอบยอดคงเหลือนอกเชนต่อคำมั่นสัญญาบนเชน ในขณะที่เนื้อหาใบเสร็จยังคงอยู่ในชั้นข้อมูลนอกเชน

ลำดับการเผยแพร่บัญชีแยกประเภทราคาสาธารณะและหลักฐานการรวมใบเสร็จส่วนตัวระบุไว้ในส่วน 06
