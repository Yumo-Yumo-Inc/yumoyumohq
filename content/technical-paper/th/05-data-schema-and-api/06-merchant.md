# ผู้ค้า (normative)

## 5.5 ผู้ค้า (normative)

```json
// Merchant
{
  "merchant_id": "f3b1c2d4-...",
  "display_name": "Migros",
  "name_aliases": ["MIGROS T.A.S.", "MIGROS A.S."],
  "tax_id": "6200278131",
  "city": "Istanbul",
  "country": "TR",
  "merchant_class": "supermarket",
  "first_seen_at": "2026-01-01T00:00:00Z",
  "last_seen_at": "2026-05-17T14:23:11Z",
  "receipt_count": 18432
}
```

`tax_id` คือหมายเลขประจำตัวผู้เสียภาษีทางการของผู้ค้า (ในตุรกีคือ *Vergi Kimlik Numarası* 10 หลัก) จัดเก็บเป็น**ฟิลด์ที่ผ่านการตรวจสอบ**: ค่าที่สกัดออกมาต้องผ่านการตรวจสอบเลขตรวจสอบ (check digit) ก่อนจึงจะถูกยอมรับ ดังนั้นค่าที่ OCR อ่านผิดหรือหมายเลขที่โมเดลปั้นขึ้นจะถูกทิ้งแทนที่จะถูกเขียนลงฐานข้อมูล เมื่อรวมกับ `country` หมายเลขผู้เสียภาษีที่ผ่านการตรวจสอบทำให้ผู้ค้ามีอัตลักษณ์ที่มั่นคงข้ามรูปแบบชื่อที่หลากหลาย — เครือข่ายเดียวกันที่พิมพ์เป็น "MIGROS T.A.S." และ "MIGROS A.S." จะถูกจับคู่เป็นบันทึกเดียว

การจับคู่ผู้ค้าซ้อนสัญญาณสามชั้น: **แบรนด์ที่รู้จัก** (การสะกดทางการของเครือข่าย ซึ่งถูกระบุระหว่างการสกัดข้อมูล) **หมายเลขผู้เสียภาษีที่ผ่านการตรวจสอบ** และการจับคู่ชื่อที่ผ่านการทำให้เป็นรูปแบบมาตรฐาน แบรนด์มีลำดับความสำคัญก่อนเมื่อมีอยู่ ส่วนหมายเลขผู้เสียภาษียืนยันหรือสร้างอัตลักษณ์เมื่อชื่อมีสัญญาณรบกวน

อัตลักษณ์ผู้ค้าสาธารณะคือ **แบรนด์ + เมือง + ประเทศ** พื้นผิวที่เผยแพร่ใด ๆ — รวมถึงบัญชีแยกประเภทราคาสาธารณะ — จะแสดงผู้ค้าที่ระดับความละเอียดนี้เท่านั้น รายละเอียดระดับสาขาและระดับที่อยู่คงอยู่ในชั้นปฏิบัติการและไม่ถูกเผยแพร่
