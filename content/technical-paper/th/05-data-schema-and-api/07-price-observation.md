# การสังเกตราคา (normative)

## 5.6 การสังเกตราคา (normative)

บันทึกราคาสาธารณะอยู่ในตาราง `price_epoch_observations` หนึ่งแถวคือการสังเกตหนึ่งรายการที่**ไม่ผูกกับตัวตน** ซึ่งถูกผูกมัด (commit) เป็นใบ (leaf) เข้าไปในต้นไม้ Merkle ของ epoch รายวัน (ดู 5.9) ฟิลด์ถูกจัดเก็บในรูปแบบมาตรฐานแล้ว ตรงตามที่เข้าสู่ preimage ของใบทุกประการ ดังนั้นแฮชของใบและแถวใน manifest ที่เผยแพร่สามารถคำนวณซ้ำได้ตรงกันทุกไบต์

```text
// price_epoch_observations row (labeled plain text; published as a pipe-separated manifest line)
epoch_number:         214
leaf_index:           1082
leaf_hash:            0x9a01...            // keccak256 of the observation preimage
canonical_product_id: 3f6a...-...          // catalog id; name/brand/pack travel with it
category_path:        food.dairy.milk
country:              TR
city:                 Istanbul
merchant:             Migros               // brand string — brand + city + country only
obs_date:             2026-05-17           // date only, deliberately no time of day
unit_price:           23.50                // canonical decimal string, 2 dp
currency:             TRY
unit_type:            piece
pack_size:            1 L
```

การตัดสินใจเชิงออกแบบที่รูปร่างนี้แบกรับไว้:

- **มีเฉพาะวันที่ ไม่มีเวลาในวัน** การเผยแพร่เวลาประทับพร้อมกับผู้ค้าและวันที่จะทำให้ใครก็ตามจัดกลุ่มรายการของตะกร้าซื้อของครั้งเดียวกลับมาได้ ซึ่งประกอบโปรไฟล์การจับจ่ายขึ้นใหม่ได้แม้ไม่มีชื่อ การตัดเวลาออกเป็นค่าคงที่ด้านความเป็นส่วนตัวของบัญชีแยกประเภท ไม่ใช่ช่องว่างของข้อมูล
- **ผู้ค้าคือแบรนด์ + เมือง + ประเทศ** การสังเกตระบุสตริงแบรนด์ที่ระดับความละเอียดของเมือง อัตลักษณ์ระดับสาขาและที่อยู่ไม่ถูกเผยแพร่
- **ไม่มีการเชื่อมโยงผู้ใช้** แถวไม่มีชื่อผู้ใช้ กระเป๋าเงิน id ใบเสร็จ หรือคะแนนความน่าเชื่อถือรายแถว การควบคุมคุณภาพเกิดขึ้นต้นทาง: เฉพาะรายการจากใบเสร็จ verified เท่านั้นที่เข้าสู่การสร้าง epoch ดังนั้นชุดข้อมูลที่เผยแพร่ไม่จำเป็นต้องมีคะแนนรายการสังเกต
- **อัตลักษณ์สินค้าอธิบายตัวเองได้** preimage ของใบรวมชื่อสินค้า แบรนด์ และขนาดบรรจุ ดังนั้นบุคคลที่สามใช้บันทึกได้โดยไม่ต้องพึ่งบริการค้นหาเพิ่มเติม

บันทึกนี้ขับเคลื่อน:

1. **ความจำราคาผู้ใช้** — "คุณจ่าย 23.50 TL สำหรับ Pınar süt ที่ Migros ค่ามัธยฐานล่าสุดคือ 22.10 TL"
2. **ประวัติราคาแบบเปิด** — ใครก็ตามสามารถสร้างชุดข้อมูลขึ้นใหม่จาก manifest ที่เผยแพร่ และสืบค้นอนุกรมราคาตามแบรนด์ + เมือง + ประเทศ
3. **ดัชนีสรุป** — ชั้นข้อมูลสรุปที่ไม่ระบุตัวตน (5.8) คำนวณจากการสังเกตชุดเดียวกัน
