# ชั้นข้อมูล (สรุป Vision)

## 5.1 ชั้นข้อมูล (สรุป Vision)

Vision Paper กำหนดชั้นข้อมูล ส่วนนี้จับคู่แต่ละชั้นกับที่เก็บข้อมูลเฉพาะ และแสดงว่าสามารถสืบค้นอะไรจากอะไรได้

| ชั้น | สิ่งที่อยู่ที่นี่ | การเข้าถึงผู้ใช้ | การเข้าถึงปฏิบัติการ | การเข้าถึง B2B |
|---|---|---|---|---|
| **อุปกรณ์** | ภาพใบเสร็จต้นฉบับ | ข้อมูลของตน | ขอบเขตอุปกรณ์ | ขอบเขตอุปกรณ์ |
| **ระบบบันทึกหลัก** | บันทึกใบเสร็จ รายการสินค้า เหตุการณ์รางวัล — Postgres แบบ managed ตัวเดียว (Neon) | ข้อมูลของตน | ปฏิบัติการ | ชั้นข้อมูลสรุป |
| **ข้อมูลสรุปที่ไม่ระบุตัวตน** | แผงข้อมูลและดัชนี k-anonymous | มุมมองสรุป | ปฏิบัติการ | มุมมองสรุป |
| **สรุปบนเชน** | ราก Merkle ของ epoch (รางวัล + ราคา) เหตุการณ์ INT | สาธารณะ | สาธารณะ | สาธารณะ |

การแบ่งชั้นร้อน/อุ่นตามอายุข้อมูลของระบบบันทึกหลักเป็น**ทางเลือกสำหรับการขยายระบบ** ซึ่งวางแผนไว้เมื่อปริมาณข้อมูลถึงจุดที่คุ้มค่า ปัจจุบัน Postgres อินสแตนซ์เดียวเก็บประวัติทั้งหมด

กฎที่เคร่งครัด: **ข้อมูลสรุปที่ไม่ระบุตัวตนถูกแยกจากบันทึกผู้ใช้รายเดียว** 5.8 ระบุการแปลง
