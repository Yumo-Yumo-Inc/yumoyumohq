# ขั้นตอนที่ 2 — การแยกข้อมูลเชิงโครงสร้าง

## 2.5 ขั้นตอนที่ 2 — การแยกข้อมูลเชิงโครงสร้าง

ขั้นตอนนี้แปลงเอกสารให้เป็นฟิลด์ใบเสร็จเชิงโครงสร้าง สัญญาสาธารณะคือชุดฟิลด์และพฤติกรรมของขั้นตอน ส่วนผู้ให้บริการโมเดล ข้อความพรอมป์ นโยบายการกำหนดเส้นทาง งบประมาณโทเคน และเงื่อนไขการลองใหม่ จะถูกจัดการในชั้นปฏิบัติการภายใน

### ขอบเขตการกำหนดเส้นทางโมเดล

Yumo Yumo ดำเนินการแยกข้อมูลเชิงโครงสร้างผ่านอินเทอร์เฟซที่ไม่ขึ้นกับโมเดล นโยบายปฏิบัติการสามารถเลือกเอนจินที่เหมาะสมตามภาษา ความซับซ้อนของเอกสาร สถานะสุขภาพ และสัญญาณด้านคุณภาพ ลำดับการเลือกและพฤติกรรมสำรองของนโยบายนี้ยังคงเป็นข้อมูลภายใน

### ผลลัพธ์เชิงโครงสร้าง — ข้อความล้วนแบบติดป้ายกำกับ

โมเดลส่งคืน**ฟิลด์ข้อความล้วนแบบติดป้ายกำกับ** หนึ่งฟิลด์ต่อบรรทัด แทนที่จะเป็นออบเจกต์ JSON ผลลัพธ์ JSON จากโมเดลภาษานำมาซึ่งความล้มเหลวในการ parse ประเภทหนึ่งของมันเอง — อักขระควบคุมที่ไม่ได้ escape วงเล็บที่ไม่ปิด เครื่องหมายจุลภาคเกินมา — ซึ่งอักขระผิดรูปเพียงตัวเดียวทำให้การตอบสนองทั้งหมดใช้ไม่ได้ บรรทัดแบบติดป้ายกำกับเสื่อมสภาพอย่างนุ่มนวล: บรรทัดที่หายไปหรือผิดรูปทำให้ฟิลด์เดียวว่างเปล่า ในขณะที่ฟิลด์อื่นทุกฟิลด์ยังคง parse ได้

ฟิลด์ส่วนหัวมาในบล็อกที่มีตัวคั่น:

```
document_type: receipt
merchant_legal_name: MIGROS TICARET A.S.
merchant_display_name: MIGROS
receipt_date: 2026-05-17
currency: TRY
total_paid: 276.71
total_vat: 42.21
payment_method: visa
...
```

รายการสินค้ามาเป็น**ตารางคั่นด้วยเครื่องหมาย pipe** ที่มีลำดับคอลัมน์ตายตัว:

```
LINE | NAME | BRAND | QTY | UNIT | UNIT_PRICE | TOTAL | VAT_RATE
1 | SUT 1L | PINAR | 2 | adet | 23.50 | 47.00 | 0.01
2 | ...
```

ชุดฟิลด์ครอบคลุมอัตลักษณ์ผู้ค้า (ชื่อตามกฎหมาย ชื่อที่แสดง แบรนด์ที่ระบบรู้จัก ตัวระบุภาษี ส่วนของที่อยู่) ข้อมูลเมตาของเอกสาร (ประเภท วันที่ เวลา หมายเลขใบเสร็จ ประเทศ สกุลเงิน) ยอดรวมและภาษี วิธีการชำระเงินและหลักฐานการชำระเงิน และตารางรายการสินค้า

### การ parse เชิงป้องกัน

ตัว parse ปฏิบัติต่อทุกฟิลด์อย่างเป็นอิสระ: ฟิลด์ที่หายไปกลายเป็น `null` ค่าที่ผิดรูปกลายเป็น `null` และแถวรายการสินค้าที่เสียหายจะถูกบันทึกลงล็อกแล้วข้ามไป การ parse ไม่โยน exception เลย — ไพพ์ไลน์ดำเนินการต่อด้วยฟิลด์เท่าที่กู้คืนมาได้ และชั้นกฎ (2.6) ตรวจสอบยอดรวม วันที่ สกุลเงิน รายการสินค้า และฟิลด์ภาษีเทียบกับข้อความของใบเสร็จ

### การจัดการความสอดคล้อง

หากผลการแยกข้อมูลมีสัญญาณคุณภาพต่ำ หรือชั้นกฎพบความไม่สอดคล้อง ไพพ์ไลน์สามารถส่งผลลัพธ์ไปให้ตรวจสอบหรือประมวลผลใหม่ได้ การเลือกเส้นทางจะถูกควบคุมผ่านพารามิเตอร์ด้านปฏิบัติการ
