# กลไกเศรษฐกิจ

## กลไกเศรษฐกิจ

- **TGE (Token Generation Event)** — ช่วงเวลาที่ INT กลายเป็นสินทรัพย์บนเชนที่ใช้งานได้ และการสะสม bINT ที่มีสิทธิ์เรียกร้องได้
- **เส้นโค้งการปล่อย** — กำหนดการปล่อยรางวัลผู้ใช้ มาตรฐานตามแถบผู้ใช้งานประจำเดือน *ดู: 04*
- **อัตราส่วนการแปลง (bINT → INT)** — ตั้งไว้ที่ 1:1: หน่วย bINT หนึ่งแปลงเป็นสิทธิ์เรียกร้อง INT หนึ่งหน่วย *ดู: 04*
- **เพดาน bINT รายวัน** — จำนวน bINT สูงสุดที่ผู้ใช้สามารถได้รับต่อวัน เพดานถูกกำหนดโดยระดับบัญชีของผู้ใช้ สถานะความน่าเชื่อถือของผู้ใช้ส่งผลต่ออัตราการให้รางวัลที่ใช้กับใบเสร็จแต่ละรายการ *ดู: 03 Trust Layer, 04 Tokenomics Mechanics*
- **ซื้อคืนและเผา (BBB)** — กลไกการเผาตามกฎเกณฑ์ที่ใช้ภายใต้นโยบายคลังสำรองเพื่อลดการหมุนเวียนของ INT รายละเอียดการดำเนินการเป็นปฏิบัติการ *ดู: 04*
- **Liquidity Bootstrapping Pool (LBP)** — รูปแบบพูล DEX ที่ใช้เปิดตัวโทเค็นใหม่ด้วยน้ำหนักที่ปรับได้ พิจารณาสำหรับสภาพคล่อง INT เริ่มต้น
- **Single-sided LP** — การจัดหาสภาพคล่องที่ต้องการสินทรัพย์เพียงหนึ่งในสองของคู่ ใช้เพื่อเริ่มต้นพูล INT เริ่มต้นด้วย LP ที่ถูกล็อก
