# Экономические механики

## Экономические механики

- **TGE (Token Generation Event)** — Момент, когда INT становится живым on-chain-активом, а накопленное право на bINT становится доступным для получения.
- **Эмиссионная кривая** — График эмиссии вознаграждений пользователей, масштабируемый диапазонами ежемесячных активных пользователей. *См.: 04.*
- **Конверсионное соотношение (bINT → INT)** — Зафиксировано 1:1: одна единица bINT конвертируется в право на получение одного INT. *См.: 04.*
- **Ежедневный потолок bINT** — Максимальное количество bINT, которое пользователь может заработать в день. Потолок задаётся уровнем аккаунта пользователя; статус доверия пользователя влияет на ставку вознаграждения, применяемую к каждому отдельному чеку. *См.: 03 Уровень доверия, 04 Токеномические механики.*
- **Buy-back-and-burn (BBB)** — Механизм сжигания на основе правил, используемый в рамках казначейской политики для сокращения обращения INT. Детали исполнения операционные. *См.: 04.*
- **Liquidity Bootstrapping Pool (LBP)** — Формат DEX-пула для запуска новых токенов с регулируемыми весами. Рассматривается для начальной ликвидности INT.
- **Single-sided LP** — Предоставление ликвидности, требующее только один из двух активов пары. Используется для начального пула INT с заблокированной LP.
