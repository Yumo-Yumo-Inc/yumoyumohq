# Токены и on-chain-активы

## Токены и on-chain-активы

- **INT** — Передаваемый utility-токен Yumo Yumo, выпущенный на Solana как SPL-токен (decimals = 6, total supply = 99,000,000,000). *См.: 04 Токеномические механики.*
- **bINT** — Внеблокчейн-учётный кредит, отражающий верифицированный вклад пользователя. Подходящий баланс в epoch-расчёте даёт право на получение INT по фиксированному соотношению 1:1. *См.: 04 Токеномические механики.*
- **Proof-of-expense SBT** — NonTransferable-токен стандарта Token-2022, чеканящийся один раз на аккаунт в кошелёк пользователя и помечающий аккаунт как верифицированного участника расходов. *См.: 04 Токеномические механики, 06 Верифицируемая публикация.*
- **SPL Token** — Стандарт токенов Solana Program Library. «ERC-20 Solana.» Используется для INT.
- **Token-2022** — Стандарт токенов Solana с расширениями. Используется для proof-of-expense SBT с расширением NonTransferable.
- **Soulbound** — Поведение токена, привязанное к одному кошельку на протяжении жизни актива.
