# Утилитарность INT

## 4.27 Утилитарная поверхность

INT выполняет шесть функций внутри протокола Yumo Yumo. У функции вознаграждения инфраструктура расчёта и получения построена, активация ожидается; остальные запланированы и активируются по мере созревания поверхности протокола.

| Функция | Статус | Описание |
|---|---|---|
| **Актив вознаграждения** | Инфраструктура готова, активация ожидается | Верифицированные вклады в настоящее время накапливаются в учётном слое bINT (4.14). Путь расчёта и получения для жизненного цикла конверсии bINT → INT (4.4) построен; распределение INT в блокчейне активируется с Token Generation Event |
| **Актив стейкинга** | Запланирована | Если стейкинг будет включён, держатели смогут блокировать INT в уровневых стейкинговых пулах (4.6) |
| **Выкуп и сжигание** | При включении политики | Казначейство может покупать и сжигать INT по опубликованной политике (4.9) |
| **Сжигание за отчёт данных** | Запланирована | Бизнесы, получающие агрегированные отчёты данных сообщества, обязаны сжечь определённое количество INT за каждый отчёт (4.30) |
| **Сигнал управления** | Запланирована | Взвешенное по INT сигнализирование для решений по приоритетам продукта данных, распределению казначейства и грантам экосистемы |
| **Связанный API-доступ** | Запланирована | Потребители API анонимизированного продукта данных могут быть обязаны блокировать INT в качестве обеспечения своих ключей доступа |

## 4.28 Политика выручки казначейства

INT не обещает доходность, рост стоимости или поддержку цены. Если продукт данных или другая деятельность приносит выручку, её распределение в казначейство, на операции, стимулы стейкинга либо выкуп и сжигание возможно только по опубликованной политике и после необходимой юридической проверки.

Любое распределение выручки или стимул стейкинга публикуется с суммой, периодом, уполномоченным лицом, принявшим решение, и записью в блокчейне. Этот раздел не создаёт обязательств по будущей выручке, сжиганиям или выплатам за стейкинг.

## 4.29 Возможные источники выручки

Возможные источники выручки, подпадающие под политику казначейства:

- **Продажи анонимизированных данных.** k-анонимизированные, агрегированные данные на уровне чеков, продаваемые FMCG-брендам, розничным сетям, исследовательским фирмам и разработчикам через уровневый API-доступ.
- **Партнёрская и реферальная выручка.** Переходы по сравнению цен к розничным или купонным партнёрам (запланировано).
- **Премиум-подписка.** Расширенная персональная аналитика и функции автоматизации целей (запланировано).

Детали генерации выручки и архитектура анонимизации описаны в 05 Схема данных и API.

## 4.30 Сжигание за отчёт данных

Планируемая модель доступа к отчётам данных может требовать сжигания INT для определённых типов отчётов. Если модель будет включена, сжигание записывается в блокчейне, а тип отчёта и объём публикуются.

Сжигание уменьшает количество INT в обращении; оно не гарантирует результат для цены, стоимости или спроса на токен. Объём сжигания за отчёт вступает в силу только после публикации применимой политики казначейства и цены продукта.
