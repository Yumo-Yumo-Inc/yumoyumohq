# B2B API (в планах)

## 5.11 B2B API (в планах)

API для B2B-продукта данных — **запланированная будущая работа**; сегодня B2B-эндпоинты не работают. Данные, значимые для B2B, сейчас попадают во внешний мир через публичный ценовой реестр (5.10) и его манифесты Arweave.

Эскиз дизайна планируемой поверхности — отдельный базовый путь, отдельные учётные данные, отдельные квоты от публичного API:

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/inflation-pulse` | Серия Inflation Pulse |
| GET | `/basket-panel` | Запрос Basket Panel |
| GET | `/merchant-benchmarks` | Merchant Benchmarks |
| POST | `/cohort-query` | Пользовательская когорта с соблюдением k-порога |
| GET | `/catalog` | Доступные продукты + свежесть + ценообразование |
| GET | `/methodology/{version}` | Документ методологии для данной версии |

Планируемая авторизация: API-ключ с подписью запросов и защитой от повтора; схема подписи и окно повтора остаются во внутреннем операционном слое.

Каждый планируемый B2B-ответ включает `methodology_version`, индикатор k-анонимного порога и число участников ответа, чтобы команда compliance покупателя могла проверить выпуск.
