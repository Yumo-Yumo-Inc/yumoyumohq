# Версионирование

## 5.13 Версионирование

- **Версии спецификации реестра** работают уже сегодня: каждый прообраз листа ценового реестра и каждый манифест несут версию спецификации (`v1`, с версионируемым переходом формата, привязанным к номеру epoch), поэтому запечатанная история всегда пересобирается байт в байт по правилам, с которыми была опубликована.
- **Версии API** (в планах, для публичного REST API): префикс в URL (`/v1`, `/v2`), две соседние основные версии работают параллельно минимум 12 месяцев.
- **Версии таксономии** независимы от версий схем. Канонический продукт может перемещаться из `food.dairy.milk` (v1.0) в `food.dairy.fluid-milk` (v1.1), в то время как схема записи чека остаётся стабильной.
