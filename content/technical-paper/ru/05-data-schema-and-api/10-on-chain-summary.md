# Сводка данных в блокчейне

## 5.9 Сводка данных в блокчейне

Что размещается в блокчейне, по категориям:

| В блокчейне | Вне блокчейна |
|---|---|
| Корень Меркла reward-epoch (memo-печать) | Отдельные строки `contribution_point_events` |
| Корень Меркла price-epoch + хэш манифеста (memo-печать) | Балансы bINT и записи начислений |
| События mint и transfer INT (в планах) | Записи начисления вознаграждений на пользователя |
| Переходы уровней NFT (в планах) | Сырой текст OCR |
| | Изображения чеков и строки чека |
| | Сигналы оценки доверия |

Правило: **в блокчейне хранятся обязательства и агрегаты; вне блокчейна хранится содержимое.** Пользователь может проверить свой внеблокчейн-баланс по обязательству в блокчейне, при этом содержимое чеков остаётся во внеблокчейн-слое данных.

Поток публикации публичного ценового реестра и частное доказательство включения чека определены в разделе 06.
