# Уровни данных (рекап Vision)

## 5.1 Уровни данных (рекап Vision)

Vision Paper определяет уровни данных; данный раздел отображает каждый на конкретное хранилище и показывает, что доступно для запросов из чего.

| Уровень | Что здесь находится | Доступ пользователя | Доступ операций | Доступ B2B |
|---|---|---|---|---|
| **Устройство** | Исходное изображение чека | Свои данные | Область устройства | Область устройства |
| **Система записи** | Записи чеков, строки, события вознаграждений — единый управляемый Postgres (Neon) | Свои данные | Операционный | Агрегированный слой |
| **Анонимизированный агрегат** | k-анонимные панели и индексы | Агрегированное представление | Операционный | Агрегированное представление |
| **Сводка в блокчейне** | Merkle-корни эпох (вознаграждения + цены), события INT | Публичный | Публичный | Публичный |

Разделение системы записи на горячий/тёплый уровни по возрасту данных — **опция масштабирования**, запланированная на момент, когда объём этого потребует; сегодня один экземпляр Postgres хранит всю историю.

Строгое правило: **анонимизированный агрегат отделён от записей отдельного пользователя**. 5.8 определяет преобразование.
