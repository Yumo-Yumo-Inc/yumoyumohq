# Economic mechanics

## Economic mechanics

- **TGE (Token Generation Event)** — The moment INT becomes a live, on-chain asset and accumulated bINT entitlement becomes claimable.
- **Emission curve** — The user-reward emission schedule, scaled by Monthly Active User bands. *See: 04.*
- **Conversion ratio (bINT → INT)** — Fixed at 1:1: one unit of bINT converts into one INT claim entitlement. *See: 04.*
- **Daily bINT ceiling** — The maximum bINT a user can earn per day. The ceiling is set by the user's account level; a user's trust standing influences the reward rate applied to each individual receipt. *See: 03 Trust Layer, 04 Tokenomics Mechanics.*
- **Buy-back-and-burn (BBB)** — Rule-based burn mechanism used under treasury policy to reduce INT circulation. Execution detail is operational. *See: 04.*
- **Liquidity Bootstrapping Pool (LBP)** — A DEX pool format used to launch new tokens with adjustable weights. Considered for initial INT liquidity.
- **Single-sided LP** — Liquidity provision that requires only one of the two assets in a pair. Used to seed the initial INT pool with locked LP.
