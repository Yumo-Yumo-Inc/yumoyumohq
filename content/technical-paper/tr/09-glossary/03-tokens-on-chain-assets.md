# Token'lar ve zincir üstü varlıklar

## Token'lar ve zincir üstü varlıklar

- **INT** — Yumo Yumo'nun devredilebilir kullanım token'ı; Solana üzerinde SPL token olarak basılır (ondalık = 6, toplam arz = 99.000.000.000). *Bkz: 04 Tokenomik Mekanikleri.*
- **bINT** — Kullanıcının doğrulanmış katkısını izleyen zincir dışı muhasebe kredisi. Uygun bakiye epoch mutabakatında sabit 1:1 oranıyla INT talep hakkına dönüşür. *Bkz: 04 Tokenomik Mekanikleri.*
- **Proof-of-expense SBT** — Hesap başına bir kez kullanıcının cüzdanına basılan, hesabı doğrulanmış harcama katkıcısı olarak işaretleyen Token-2022 NonTransferable token. *Bkz: 04 Tokenomik Mekanikleri, 06 Doğrulanabilir Yayın.*
- **SPL Token** — Solana Program Library token standardı. Solana'nın "ERC-20"sidir. INT için kullanılır.
- **Token-2022** — Solana'nın eklenti destekli token standardı. NonTransferable eklentisiyle proof-of-expense SBT için kullanılır.
- **Soulbound** — Varlığın ömrü boyunca tek bir cüzdana bağlı token davranışı.
