## 5.14 SDK yol haritası

SDK'lar planlanan açık REST API'yi (5.10) izler; aşağıdaki gösterge niteliğindeki sıra, o yüzey yayına girdikten sonra başlar.

| Çeyrek (gösterge) | SDK |
|---|---|
| Q+1 | TypeScript SDK (açık API) |
| Q+1 | Solana programı TypeScript bağlamaları |
| Q+2 | Swift / Kotlin mobil SDK |
| Q+3 | B2B için Python SDK |
| Q+4 | Araştırma için R / Stata SDK |

B2B Python SDK ayrı bir ağırlık taşır — çoğu B2B alıcının veri ekibi varsayılan olarak Python kullanır.
