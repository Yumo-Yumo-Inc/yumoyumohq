# Behavioral Interventions and Ethics

Patterns should help people notice habits and take small, voluntary steps. It should not shame, scare, or trap them.

## What works better than budgeting lectures

Research and product practice point us toward:

- **Curiosity first** — prediction games and “what do you expect this week?” beats static budget scolding
- **Commitment devices** — specific, forward-looking rules the user chooses (“no late grocery delivery this week”)
- **Just-in-time, factual prompts** — timed to the user's own high-intensity windows
- **High self-efficacy copy** — name an easy action the user can complete today

We do not rely on shame, fear, or public humiliation as engagement tactics.

## Interventions we design for

| Intervention | Patterns shape |
|---|---|
| Prediction game | User guesses this week's café share; we reveal the receipt truth |
| Soft limit | User sets a gentle ceiling on a bucket or time window |
| Commitment rule | User picks one merchant or window to pause |
| Habit-loop rewrite | Swap one trigger routine for a lighter alternative |
| Evidence review | Open the “why?” chips before changing anything |

## Peer comparison caution

Peer benchmarks can help heavy spenders recalibrate, but they can also pull careful spenders upward. Rules:

- Show peer context only with a real cohort
- Prefer “people with a similar grocery rhythm” over broad city averages when possible
- Never push low spenders to “catch up”
- Keep an easy dismiss and an empty state when cohorts are thin

## Tone

- Supportive mirror, not judge
- Gain framing over loss framing when both are accurate
- Celebrate eudaimonic spends (learning, health, tools) without moral ranking of every comfort purchase
- Ask “does this still feel worth it?” for repeating comfort loops

## Dark patterns we refuse

- Confirmshaming dismissals (“No, I like wasting money”)
- Fake urgency or fake scarcity on insight cards
- Hiding the exit from a nudge flow
- Pretending thin data is a confident diagnosis
- Selling or implying sale of individual receipt data

## Explainability

When we show a score or trait, we show the receipts behind it. “We used these 11 receipts” is part of the product, not an advanced debug mode.

## Monetization ethics

Patterns exists to deepen understanding of Proof of Expense. Premium depth, if any, should buy clearer tools and coaching — not pressure, not data brokerage, not fear.
